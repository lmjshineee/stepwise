C++ · 对象与引用约 2 分钟

给引用赋值，会让它换一个对象吗？

先有一个值为 3 的整数 n，再用 int& r = n 声明引用。r 是 n 的另一个名字：通过 r 读写，操作的仍然是那个整数。这里没有复制出第二个整数。

现在创建另一个整数 m，初始值为 7，再执行 r = m。结果是 n 变成 7，通过 r 读到的也是 7。赋值把 m 的值写进 n，并没有让 r 转而引用 m。

接着把 m 改成 8，n 和 r 仍然读到 7。把“创建时绑定谁”和“之后把什么值写进去”分开，就能解释为什么引用初始化后不能靠赋值重新绑定。

想一想

如果接下来执行 ++r，n 和 m 中的哪一个会改变？

展开思考与解释

改变的是 n：它变成 8，m 仍然是之前的 8。两个数碰巧相同，也不代表它们是同一个对象。判断引用关系，要追踪对象身份，而不只是比较数值。

计算机基础 · 内存约 2 分钟

同样读 16 个数，为什么搬运次数不同？

把一个 4×4 矩阵按行连续存放，下标依次为 0 到 15。现在约定一个小模型：一条缓存行能装 4 个元素，矩阵起点与缓存行对齐；缓存只能保留一行，最初为空。读到不在缓存里的数，就装入它所在的整行，并换掉旧行。

按行读时，前四步是 0、1、2、3。第一次装入的数据，接下来又用了三次。遍历完四行，只需要装入 4 次。按列读时，前四步却是 0、4、8、12，每一步都换一条缓存行。回到下标 1 时，最早的那行也已经被换走。完整遍历要装入 16 次。

两种顺序都读了 16 个数，差别在于“一次搬来的数据，来得及用几次”。4 次和 16 次是这个模型的装入次数，不能直接换算成真实 CPU 的四倍速度；真实缓存容量、预取和其他开销还会影响计时。

想一想

如果缓存能同时保留矩阵的全部四行，按列遍历还会每次都重新装入吗？

展开思考与解释

在同样初始为空、没有其他数据干扰的模型里，四行各装入一次后就可以继续命中。访问顺序的影响要和容量一起判断，不能脱离条件记住“按列一定慢四倍”。

深度学习 · 训练直觉约 2 分钟

更新方向对了，损失为什么反而变大？

先用一个参数 w 做预测：预测值等于 w×x。只有一个样本，输入 x=2，目标 y=4，初始 w=1，预测便是 2。用“预测与目标之差的平方，再除以 2”作为损失，当前损失是 2。

此时损失对 w 的导数是 −4。负号说明，在当前位置附近，稍微增大 w 能降低损失。梯度下降按“新参数 = 旧参数 − 学习率×导数”更新。学习率取 0.1，w 变成 1.4，预测变成 2.8，损失降到 0.72。

如果把学习率改成 1，同一个更新规则却会把 w 推到 5，预测变成 10，损失升到 18。方向仍然是增大 w，但这一步跨过了合适的位置。导数提供局部方向，不保证任意大的步长都能改善结果。

想一想

只记录“梯度是负的”和“参数变大了”，足以确认这次训练更新有效吗？

展开思考与解释

还要用新参数重新计算预测与损失。这个单样本上的改善也只是训练过程的一步，是否能处理没见过的数据，需要另外检查。

CS336 · 分词机制约 2 分钟

四个 a 里有三个 aa，为什么只合并两次？

字节对编码（BPE）会把常见的相邻词元合并成新词元。先把 aaaa 写成四个字节编号：[97, 97, 97, 97]。相邻的两个 97 一共出现三次，分别跨位置 0–1、1–2、2–3。这里统计的是相邻对，允许它们重叠。

现在给这一对分配新编号 256，并从左到右替换。前两个 97 合成一个 256，后两个 97 再合成一个 256，最终得到 [256, 256]。中间那一对不能再合并，因为它的两个旧词元已经分别被用掉了。

统计出现了几次，与本轮实际替换了几次，是两种计数。前者帮助决定学哪一条合并规则，后者必须遵守每个旧词元只能被消费一次的边界。把这两步混成一步，小分词器就容易出现重复使用输入的问题。

想一想

如果输入缩成 aaa，同一条规则从左到右应用一次，会得到什么编号序列？

展开思考与解释

结果是 [256, 97]。前两个 a 被合并，最后一个保留。保存新编号对应的字节后，把它们拼接起来，仍然能还原出原来的 aaa。

AI Agent · 工具与反馈约 2 分钟

模型说“读过了”，程序就真的读过了吗？

让模型根据一条资料回答问题，它先给出 read_note 请求，参数是 release。此时发生的只是一个行动提议：资料还没有被读取。模型写出“已经读过”也不会让宿主中的读取函数自动运行。

宿主检查工具名称和参数，真正执行读取，再把结果作为观察交回。回传带着原请求的 call_id，模型才能知道哪次请求得到了什么。即使宿主内部已经读到数据，漏掉回传，下一轮模型仍然看不到它。

这解释了为什么工具调用不能只看最后一段文字。要追踪提议、实际执行和反馈三件事；模型按反馈继续选择动作，才能形成与环境交互的循环。固定回放可以测试这条通路，却不能替代自主判断。

想一想

工具执行成功，但结果回传用了另一次调用的 ID，还能把它视为这次请求的可靠观察吗？

展开思考与解释

不能。结果内容可能真实，却属于错误的请求。call_id 标识一次调用，资料 ID 标识被读取的记录；两个身份各自回答不同的问题。

AI Agent · 证据与判断约 2 分钟

引用真实，为什么答案仍然可能是错的？

一条资料写着“构建通过只说明产物能生成，还要检查边界”。Agent 确实读过它，却回答“构建通过就保证没有缺陷”，末尾还附上正确的资料 ID。这个引用是真的，结论却把原意说反了。

程序可以机械检查引用 ID 是否存在、是否实际读过。它解决的是来源身份问题。关键判断是否受资料支持、有没有漏掉条件、有没有完成用户任务，则是另一层检查。一个合法标记不能自动完成这些判断。

因此，运行结束、工具成功、引用命中和任务正确应该分别记录。对照原文逐句判断关键结论，必要时补充反例或人工评分，才能发现“格式全对但意思错了”的答案。

想一想

如果所有引用都来自实际读过的资料，能直接把任务成功率记为百分之百吗？

展开思考与解释

不能。这只说明引用身份检查通过，还要判断资料是否支持结论，以及答案是否覆盖任务。把不同层次混成一个成功标签，会让检查结果看起来比实际能力更好。

数学 · 线性计算约 2 分钟

一个输出为什么要读一整行和一整列？

线性层的输入 X 是 2×3，权重 W 是 3×2。输出位置 (0,0) 不是把两个相同位置的元素相乘，而是把输入第一行 [1,2,3] 与权重第一列 [1,0,1] 做点积，再加偏置 0.5，得到 4.5。

被相乘并求和的是特征维。样本轴与输出轴保留下来，所以结果是 2×2。逐元素乘法没有自动做这次归约，即使 shape 恰好兼容，含义也可能完全不同。

想一想

如果输入样本数从 2 变为 5，特征和权重不变，输出 shape 会是什么？

展开思考与解释

是 (5,2)：样本轴变长，输出特征轴仍由权重的列数决定。

接着读向量与矩阵：从线性层看懂张量计算这张卡片的链接
数学 · 低秩约 2 分钟

有两列，就有两个独立方向吗？

矩阵 [[1,2],[2,4]] 的第二列总是第一列的两倍。无论输入怎么组合，输出都只能沿 [1,2] 这个方向变化，因此秩是 1。非零元素的个数并不能告诉我们独立方向有多少。

SVD 用正交方向和伸缩量组织变换。丢掉一个非零奇异值会失去对应方向的信息；固定矩阵的重建误差小，也不能代替训练效果或执行速度的验证。

想一想

2×2 矩阵拆成 2×1 与 1×2 两个因子，参数会更少吗？

展开思考与解释

不会：两个因子仍有 4 个数。要比较 r(m+n) 与 mn，不能只看“低秩”这个名字。

数学 · 微积分约 2 分钟

导数预测正确，为什么还有一点误差？

f(x)=x²，在 x=2 处的导数是 4。把 x 增加 0.1，导数给出的局部预测是函数值增加 0.4；精确变化却是 2.1²−2²=0.41。

多出来的 0.01 来自有限步长的二阶项。导数描述当前位置附近的线性变化；用它推断大步长后的结果，要考虑曲率和范围。

想一想

把步长改成 0.01，线性预测与精确变化各是多少？

展开思考与解释

预测增加 0.04，精确增加 0.0401。误差变成 0.0001，但浮点计算还会引入舍入。

接着读微积分：程序中的变化率与累计量这张卡片的链接
数学 · 反向计算约 2 分钟

一个变量走了两条路，梯度记哪一条？

令 a=xy，b=a+x，L=b²，在 x=2、y=3 时，a=6、b=8、L=64。x 一条路先进入乘法，另一条路直接进入加法，两条都能改变损失。

反向先得到 dL/db=16。直达路径给 x 贡献 16，经乘法路径再贡献 16×3=48，因此 x 的梯度是 64。写回时覆盖已有贡献，会丢掉一条真实路径。

想一想

更小的 z=x²+x，在 x=2 时梯度是多少？

展开思考与解释

是 4+1=5。共享变量的贡献要相加，这与跨训练步骤累积 .grad 缓冲还不是同一件事。

接着读计算图与梯度：手写一次线性层反向这张卡片的链接
数学 · 概率约 2 分钟

概率密度能大于 1 吗？

在 [0,0.5] 上均匀分布，密度为 2。这并不意味着某个点有 200% 的概率；连续分布的区间概率来自密度曲线下的面积。

整个支持区间的面积是 2×0.5=1。长度为 0.1、完全位于支持区间内的小段，概率是 0.2；一个精确单点的概率为零。

想一想

密度为 2，能不能直接把它当作一次事件的概率代入判断？

展开思考与解释

不能。先明确事件对应的区间，再对区间求面积；离散概率质量和连续密度需要区分。

接着读概率与统计：一批样本能告诉我们什么这张卡片的链接
数学 · 数值与分布约 2 分钟

减去最大值，为什么概率不变？

Softmax 把 exp(logit) 除以所有指数之和。把每个 logit 同时减去 c，分子分母都会乘上 exp(−c)，公因子约去，所以概率不变。

取 c 为最大 logit，指数输入就都不大于零，避免直接计算 exp(1000)。需要对数概率时直接用稳定 log-softmax，避免先下溢成 0 再取 log。

想一想

把所有 logit 加 1000，数学概率会变吗？直接指数计算的可靠性会变吗？

展开思考与解释

数学概率不变，直接求指数却更容易溢出。代数等价与数值路径可靠是两个判断。

方向对，为什么一步仍会走坏？

对 f=.5(x²+4y²)，从 (2,1) 出发，梯度是 (2,4)。学习率 0.2 更新到 (1.6,0.2)，目标从 4 降到 1.36。

这个正定二次函数在 0<η<0.5 时每个特征方向都会收缩；触到边界可能振荡。这个结论依赖函数曲率，不能直接当作所有神经网络的步长公式。

把点投影回单位球，就能不管学习率多大了吗？

展开思考与解释

不能。投影保证可行性，下降与收敛仍依赖目标、步长和其他条件。

Python · 张量布局约 2 分钟

转置换了坐标，数据一定搬家了吗？

连续 2×3 数组的元素步长是 (3,1)。转置得到 3×2，元素步长变成 (1,3)，可以只改变访问规则，仍共享原来的底层存储。

如果通过转置视图改到原来的第一个元素，原数组也会看到变化。显式独立副本则有另一块存储；shape 一样、数值一样，都不能证明两个数组独立。

展开思考与解释

不能。兼容的 NumPy 数组与该 CPU 张量共享存储；需要独立结果时明确复制，并分别核对设备与布局。

回答有真实引用，为什么还漏了一半？

用户问：“发布前检查什么，检查失败又怎样恢复？”这句话有两个需要分别回答的要求。Agent 只列出检查项目，并附上确实读过的资料 ID；引用可以完全真实，恢复方式却仍然没有答案。

先把要求记成 checks 和 rollback 两项，再检查报告是否各出现一次。查不到恢复资料时，保留 rollback 这一项并明确写缺少证据；不能把它删掉，也不能用“我会调查恢复方式”冒充已经调查的结果。

逐项齐全只是覆盖门槛。假如两项都有原文，恢复结论却把“停止上线”写成“直接上线”，文字匹配仍然发现不了反转。要求有没有被处理、资料有没有读过、结论是否由原文支持，需要分别判断。

想一想

报告列齐了两项，其中恢复一项写“缺少资料”。这比漏掉恢复项好在哪里？能算整个问题回答成功吗？

展开思考与解释

它让未解决的要求保持可见，方便决定继续检索、补充资料或向用户追问；整个问题仍有证据缺口。显式记录不足能帮助后续行动，却不能代替实际补齐证据。

接着读拆解问题，逐项核对 Agent 的证据这张卡片的链接
AI Agent · 上下文约 2 分钟

记忆压短了，为什么反而找不到答案？

一条资料既列出了发布检查项目，又说链接检查失败时去查“恢复约定”。现在要给下次提问留一句短记忆：可以保留检查清单，也可以保留“恢复约定”这个查找线索。两句都来自原文，却不一定同样有用。

下一次问的是怎样恢复。只保存检查清单，消息虽然短了，仍然缺少继续查找的线索；保存“恢复约定”，则能帮助后续搜索。输入能装进上下文，与保留了当前问题需要的信息，是两个判断。

短记忆只提供查找方向，不自动成为这次问答的证据。来源被修改或摘记被撤销后，也应重新决定哪些内容可以发送。记得一个 ID，不等于本轮已经读取了对应原文。

想一想

一段记忆逐字来自真实原文，而且比上限短，是否足以确认压缩做得好？

展开思考与解释

还要检查它是否保留了当前任务需要的条件和线索，并观察后续检索能否补齐证据。固定回放能暴露特定的丢失问题；真实模型是否受益，需要独立任务和实际运行结果。
