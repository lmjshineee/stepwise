读懂 AI 工程代码：对象、函数与最小实验项目

从对象、函数与迭代协议读懂 Python 工程，建立可运行、可验证的最小 AI 实验项目。

教程AI InfraPythonpractical
开始自测

看到 AI 工程代码里的 Config、生成器、装饰器和模块入口，不必先背完整语言手册。先写一个读配置、处理数字并交出结果的小程序，再追踪名字指向谁、函数收到什么、失败怎样传回调用者。

本篇复用计算机基础中已有的 Python 入口；后面的张量、数据管线、并发与测量接成实践分支。当前完整模块只用标准库，Python 运行基线为 3.12+。

先确认运行的是哪个解释器

运行 python3 --version 看版本，再用 python3 -c "import sys; print(sys.executable)" 查看本次程序的解释器。安装包时用 python -m pip，使 pip 与选中的解释器对应；编辑器也要选择同一个环境，不能凭“安装成功”推断当前进程能导入。

下载共用实验项目，在解压目录先运行 python3 -m infra_lab.basics。-m 按模块名运行，因此 infra_lab 包及其中相对导入具有明确上下文；不要进入包目录随意双击一个文件，期待所有相对导入都成立。

名字引用对象，数据含义由接口规定

count = 3 让名字绑定一个整数；再写 count = "three"，是重新绑定另一个对象，不是整数自己变成了字符串。对象有类型，操作要按当前对象解释。

普通 int、float、str、bool 分别表示整数、浮点数、文本和真值。None 可用来约定缺失：样本值 0 可以完全合法，空字符串也可能是合法字段，不能用一次 if not value 把它们都当成没有值。按契约区分 is None、空集合和数值范围。

== 比较值，is 比较身份；检查 None 常写 value is None，比较两个文本内容则用 ==。float 的舍入另见数值计算，不要用它表示“所有十进制数都精确”。

列表复制了外层，未必复制了里面

列表保存有序元素引用，字典按键关联值，集合用于成员检查。元组固定元素引用，但内部对象仍可能可变；([1],2) 中包含不可哈希的列表，不能仅凭最外层是元组就把它用作字典键。

第一行输出 [[1,9],[2]]，第二行多了独立追加的 [3]。外层不同，第一条内部列表却仍共享。配置、样本缓存和嵌套 batch 都可能遇到同样的问题；在需要明确隔离时选择合适的复制，而非到处深复制资源对象。

循环处理元素，迭代器记住进度

for 从可迭代对象依次取值，缩进界定循环体。enumerate(rows) 同时给出序号与元素；zip(a,b) 默认到较短输入结束，需要等长契约时可用 strict=True。

break 提前退出，continue 开始下一轮。循环后面的 else 在正常耗尽、没有 break 时执行，空输入也会进入；它不是某个 if 的 else。异常或直接 return 不属于正常耗尽。

输出 not found。把列表换成含 10 的输入，break 才会跳过 else。推导式如 [x*x for x in values] 适合短的生成规则，逻辑复杂时展开循环更容易观察中间状态。

函数接口要说明输入、结果与失败

本项目的 mean 接收一组有限数字、返回均值，拒绝空输入和非法值。类型标注可以帮助静态检查，但不会自动把任意外部数据变成合法输入；这里的检查必须真正执行。

函数先把输入变成列表，所以可以多次读取，也会占用与样本数成比例的内存。这适合本篇小例子，不是无限数据流的接口。数据管线会改为按批累计 sum/count。

可变默认值与闭包，都要追踪创建时机

def append_item(item, items=[]) 的默认列表在定义函数时创建，后续省略参数的调用会共享它。需要每次新建时，用 None 哨兵，在函数体中创建新列表。

分别输出 [1]、[2]。显式传入已有列表时，函数仍会修改它，这需要写在接口约定里。

闭包通常引用外层绑定，不一定保存创建时快照。循环里 [lambda: i for i in range(3)] 的函数随后可能都读到最后的 2；如果确实要固定本轮值，可写 lambda i=i: i，利用默认参数在该次函数创建时求值。这里是明确的绑定选择，不是“所有 lambda 自动复制外部变量”。

__post_init__ 检查构造时的 batch_size，不会自动验证任意后续赋值。需要更强不可变约束时再设计相应接口；下游管线也会在使用 batch_size 时检查，不能把类型提示当成永远正确的证明。

实例方法的 self 指当前对象。许多 AI 框架通过可调用对象或模块类组织状态；阅读时先找对象拥有的参数、缓存和行为，再看它实现了哪个协议。只处理一次纯数值转换的逻辑，普通函数往往已经足够清楚。

装饰器是接收函数、返回包装结果的调用。这个最小包装器只转发，wraps 保留名字、文档等元信息，return 保留调用结果：

实际添加计时或日志时，也要保留参数与异常行为，不能打印完结果就漏掉 return。with 则把进入和退出资源范围连在一起；文件或生成器早停后的关闭，会在下一篇沿实际数据读取讲清。

可靠脚本把失败与结果分开交付

预期的非法输入用条件检查并抛合适异常，程序入口决定如何报告与退出。不要用可能被 Python 优化模式移除的 assert 充当外部输入的唯一校验，也不要用 except Exception: pass 让失败伪装成空结果。

日志用于定位发生了什么，返回值供程序继续计算；两者分开。文件路径可用 pathlib.Path，JSON 解析后仍要检查业务字段；读取成功不意味着样本有效。

按需求选工具，别误读相似名字

按类别汇总散落记录时，可直接用 defaultdict；itertools.groupby 只合并连续相同键，不等于 SQL 对全部输入的分组。若选择先排序再 groupby，要同时考虑顺序变化与排序成本。

记录 a:1,b:2,a:3 因而得到 a:4,b:2。标准库提供规则明确的工具，但不会替你猜测数据是否按键相邻。
