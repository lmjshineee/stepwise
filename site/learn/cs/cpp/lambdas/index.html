先定义一个Lambda并直接调用三次

读完本篇，你应能写出一个接收参数并返回结果的Lambda，解释捕获保存了什么，再用谓词完成过滤和删除。

Lambda 表达式（C++11）会创建一个可调用的闭包对象。先不捕获外部状态：[] 是空捕获列表，(int value) 声明调用参数，return 给出结果；变量 twice 保存这个对象，后面用函数调用语法使用它。

三次调用使用同一个规则，输入分别是1、3、5。这里不需要函数指针转换；函数指针和其他可调用对象的比较留到后面的选读。各完整程序分别保存为 example.cpp，用 clang++ -std=c++23 example.cpp -o example && ./example 运行。

把可调用对象交给算法时，返回布尔判断的规则叫谓词，例如 count_if、remove_if。排序比较器还必须满足严格弱序：a.score >= b.score 在对象与自身比较时也返回true，违反要求；应使用严格比较，业务要求同分顺序时才另加次级键。

再观察值捕获与引用捕获

调用参数在每次调用时给出，捕获则在创建闭包时保存外部状态。[limit] 保存当时的副本，[&limit] 借用原变量；后者不会延长原变量的寿命。

预期输出：

count_if 在 <algorithm> 中，接收首尾位置与谓词，返回满足条件的元素数。值捕获仍用3，4与7通过；引用捕获看到6，只有7通过。两个闭包使用期间，原变量 limit 都仍在作用域内。

闭包创建时保存什么limit = 6 后用于判断的阈值{2, 4, 7} 中通过的元素
by_value当时的整数副本34、7，共 2 个
by_reference对原变量的借用67，共 1 个

两者都接收同样的调用参数，差异来自闭包保存的外部状态。引用捕获看到后来的修改，也承担原对象必须继续存活的条件。

选读：普通函数与Lambda如何传给算法

Lambda 表达式产生闭包对象，变量保存的是对象，而不是函数的入口地址。返回类型可以按照语言规则推导，并非只有单条 return 语句才允许推导。当 limit 为 5 时，isMoreThan(4) 的结果为 false。

选读：泛型Lambda的参数推导

两个字符串字面量不能直接用 + 拼接。应让至少一侧成为 std::string，例如 add(std::string{"Hello, "}, "World!")。

小结：把规则、状态和执行时机分开

Lambda 创建的是闭包对象。调用参数每次传入，值捕获保存创建时的副本，引用捕获观察原对象且不延长寿命；先说明这些关系，再把谓词交给算法。

统计、整理和真正删除是不同任务：remove_if 只给出逻辑末端，erase 才缩小容器，新代码可按需要用 C++20 的 erase_if。范围视图延迟读取，收集到独立容器后才保存结果；借用和拥有依然有不同寿命。
