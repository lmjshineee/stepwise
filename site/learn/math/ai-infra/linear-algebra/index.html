向量与矩阵：从线性层看懂张量计算

从一个线性层手算形状、点积与广播，区分计算量、元素存储和实际运行成本。

课程AI Infra数学基础conceptual
开始自测

一批输入是 (2,3)，权重是 (3,2)，为什么输出是 (2,2)？如果把 @ 改成 *，程序得到的还是同一种计算吗？先把一个输出算清，再谈大模型里的张量。

本篇从向量、点积走到线性层，最后估算它需要多少计算和元素存储。小算例使用 NumPy；配套项目的环境与运行命令在文末。

先把一组数当作一个对象

向量是有顺序的一组数。[1,2,3] 可以表示某个样本的三个特征，三个位置各有自己的含义；交换位置通常会改变模型输入。把多个等长样本逐行放在一起，就得到矩阵。

用 BBB 表示样本数，DDD 表示每个样本的特征数。矩阵 X∈RB×DX\in\mathbb R^{B\times D}X∈RB×D 的第 iii 行是第 iii 个样本，第 kkk 列是第 kkk 个特征。下标从 0 开始时，X1,2X_{1,2}X1,2​ 表示第二个样本的第三个特征。shape 是每个轴的长度，不是数据内容，也不是底层排列方式。

点积把两个等长向量按位置相乘，再把乘积相加：

x⋅w=∑k=0D−1xkwk.x\cdot w=\sum_{k=0}^{D-1}x_kw_k.x⋅w=k=0∑D−1​xk​wk​.

例如 [1,2,3] 与 [1,0,1] 的点积是 1×1+2×0+3×1=41\times1+2\times0+3\times1=41×1+2×0+3×1=4。它可以看成按权重汇总特征；数值大不一定意味着“语义更相似”，还受向量长度影响。

长度和误差也要说清计算规则

欧氏范数 ∥x∥2=∑kxk2\|x\|_2=\sqrt{\sum_kx_k^2}∥x∥2​=∑k​xk2​​ 衡量向量长度；[3,4] 的长度是 5。比较两个向量时，∥x−y∥2\|x-y\|_2∥x−y∥2​ 衡量差向量的长度。矩阵的 Frobenius 范数则把所有元素平方后相加、开根号，用于下一篇的重建误差。

这些量必须与尺度一起解释：把所有特征放大十倍，长度和误差也会变大。用点积或距离做检索前，要明确是否归一化以及各特征的单位。

一个输出是一行与一列的配合

本例约定样本按行保存，计算 Y=XW+bY=XW+bY=XW+b。权重 WWW 的每一列描述一个输出特征，bbb 是输出偏置：

X=[123456],W=[100111],b=[0.5,−0.5].X=\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix},\qquad W=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\qquad b=[0.5,-0.5].X=[14​25​36​],W=​101​011​​,b=[0.5,−0.5].

第一个输出是 Y0,0=1×1+2×0+3×1+0.5=4.5Y_{0,0}=1\times1+2\times0+3\times1+0.5=4.5Y0,0​=1×1+2×0+3×1+0.5=4.5。同一输入行与第二列相配，得到 Y0,1=1×0+2×1+3×1−0.5=4.5Y_{0,1}=1\times0+2\times1+3\times1-0.5=4.5Y0,1​=1×0+2×1+3×1−0.5=4.5。第二行同样计算，两个输出都是 10.5。

Yi,j=∑k=0D−1Xi,kWk,j+bj.Y_{i,j}=\sum_{k=0}^{D-1}X_{i,k}W_{k,j}+b_j.Yi,j​=k=0∑D−1​Xi,k​Wk,j​+bj​.

逐元素乘法没有完成这个归约

X * W 尝试把对应元素相乘，使用广播规则判断形状是否兼容；它不会自动对 kkk 求和。本例 (2,3) 和 (3,2) 不兼容，NumPy 会报错。即使两个矩阵恰好同为 (2,2)，* 和 @ 也仍是不同操作，不能用“程序没报错”判断公式正确。

转置 XTX^TXT 交换矩阵的行、列，shape 从 (B,D) 变为 (D,B)。它能改变哪些运算可组合，但不能为了消掉 shape 报错就随意加转置：先确认哪一个轴代表样本，哪一个轴代表特征。

广播描述复用关系，不表示复制了多份输入

偏置 shape 是 (H,)，为何能加到 (B,H) 的输出上？NumPy 从最右轴对齐：对应长度相等，或其中一个为 1，才能广播；缺失的左侧轴按长度 1 处理。

相加的 shape结果或原因
(B,H) 与 (H,)(B,H)；同一偏置用于每个样本
(B,H) 与 (B,1)(B,H)；每行一个偏置
(2,3) 与 (2,)不兼容；最右侧 3 与 2 不匹配

数学中的复用关系可以在实现中通过步长等机制表达，输入不必真的复制 BBB 份。但输出仍需保存，组合广播还可能产生很大的中间量。张量布局与数据搬运会用真实数组观察这些区别。

先估算计算，再讨论数据怎样复用

每个输出元素汇总 DDD 个乘积，共有 BHBHBH 个输出。把乘法和加法分别计一个浮点操作时，常用约定计算量约为 2BDH2BDH2BDH FLOPs；这是包含主导项的工程计数，不是逐条机器指令计数。本例为 2×2×3×2=242\times2\times3\times2=242×2×3×2=24，偏置加法另计。

若 X/W/Y 都以 float64 连续保存，它们分别有 6、6、4 个元素，元素数据合计 (6+6+4)×8=128(6+6+4)\times8=128(6+6+4)×8=128 字节，偏置另外 16 字节。这没有包含数组元数据、临时结果或框架内存池，更不是 GPU 峰值显存。

把归约维分成若干块，例如 K1,K2K_1,K_2K1​,K2​，同一个输出可以写为“两块点积结果相加”。这给分块计算提供数学依据；速度改善来自实际的数据复用、指令和硬件调度。浮点加法换了次序，结果还可能有舍入差异，见数值计算。

小结：每个轴都要有含义

向量组织特征，点积完成加权归约，矩阵乘法同时计算多组点积。shape 检查的是轴能否组合；广播、布局、存储量与运行耗时还要分别判断。读一个算子，先写出输入、输出和被消去的维度，再估算元素数与计算量。
