概率与统计：一批样本能告诉我们什么

从随机样本解释均值、方差与估计误差，正确汇总不同大小的批次。

课程AI Infra数学基础conceptual
开始自测
建议先读微积分

两个设备各自报告 loss 均值 2 和 3，直接平均得到 2.5，为什么可能是错的？因为均值不只由数值决定，还由它平均了多少个有效样本决定。概率与统计让我们把“定义的总体”“抽到的样本”和“报告的指标”分开。

先定义随机变量，再问概率

把一次请求是否超时记为随机变量 XXX：超时取 1，否则取 0。若模型规定 P(X=1)=pP(X=1)=pP(X=1)=p、P(X=0)=1−pP(X=0)=1-pP(X=0)=1−p，这就是一个伯努利分布。随机变量是把一次结果映射成数的规则；概率分布描述这些值各有多大机会出现。

连续变量需要另一种读法。设 TTT 在 0 到 0.5 秒之间均匀分布，密度为 2。密度高度大于 1 并不违法，因为区间概率来自面积：

P(0.1≤T≤0.2)=∫0.10.22 dt=0.2.P(0.1\le T\le0.2)=\int_{0.1}^{0.2}2\,dt=0.2.P(0.1≤T≤0.2)=∫0.10.2​2dt=0.2.

整个区间面积为 2×0.5=12\times0.5=12×0.5=1；单个点的概率仍为 0。密度的单位在这里是每秒，乘上时间宽度后才得到无单位概率。直方图若展示密度，高度也必须与分箱宽度一起解释。

条件概率不是把箭头倒过来

假设故障请求占 1%，检测器能标记其中 90%，却也误标正常请求中的 10%。一个请求被标记后，故障概率不是 90%。在一万个请求的期望计数中，故障且被标记的有 90 个，正常却被标记的有 990 个，因此

P(故障∣被标记)=9090+990=112.P(\text{故障}\mid\text{被标记})=\frac{90}{90+990}=\frac1{12}.P(故障∣被标记)=90+99090​=121​.

这是 Bayes 公式的计数读法：P(A∣B)=P(B∣A)P(A)/P(B)P(A\mid B)=P(B\mid A)P(A)/P(B)P(A∣B)=P(B∣A)P(A)/P(B)，要求 P(B)>0P(B)>0P(B)>0。先验比例会影响结果，不能把命中率直接读成标记的可信度。

期望与方差描述不同信息

期望是按概率加权的平均值。伯努利变量有 E[X]=pE[X]=pE[X]=p，因为 1×p+0×(1−p)=p1\times p+0\times(1-p)=p1×p+0×(1−p)=p。方差衡量围绕期望的平方偏离：

Var⁡(X)=E[(X−E[X])2]=p(1−p).\operatorname{Var}(X)=E[(X-E[X])^2]=p(1-p).Var(X)=E[(X−E[X])2]=p(1−p).

标准差是方差的平方根，单位与原变量一致；方差的单位则是原单位的平方。期望相同的分布也可能有非常不同的波动和尾部。

协方差 E[(X−E[X])(Y−E[Y])]E[(X-E[X])(Y-E[Y])]E[(X−E[X])(Y−E[Y])] 描述两个量的线性共同变化。它为 0 不能一般推出独立：例如对称取值的 XXX 与 X2X^2X2 仍有确定关系。判断独立，要回到联合分布是否能分解，不能只看相关系数。

一批均值的波动，与单个样本不同

取 nnn 个独立、同分布、方差有限的样本，其均值为 Xˉ=1n∑iXi\bar X=\frac1n\sum_iX_iXˉ=n1​∑i​Xi​。期望仍是 E[X]E[X]E[X]，方差则变为 Var⁡(X)/n\operatorname{Var}(X)/nVar(X)/n。伯努利 p=0.25p=0.25p=0.25、每批 16 个样本时，均值方差为 0.25×0.75/16=0.011718750.25\times0.75/16=0.011718750.25×0.75/16=0.01171875。

固定教学种子 106、LCG 抽样器；它与下载程序中 NumPy 的随机数流不同。相同设置可复现，有限抽样的均值和方差不会恰好等于理论值。

柱子统计的是重复生成的 batch 均值，而不是某一批里的 0 和 1。把每批数量增加，均值通常更集中；128 批得到的经验值仍会偏离理论值。这不自动说明随机数生成器或公式出错。

连续相邻请求的延迟可能相关，共享缓存、流量变化也会破坏独立同分布假设。不能把上述 1/n1/n1/n 公式不加条件地套进任意压测日志。性能篇会先确定采样单位和工作负载，再报告分布。

合并均值时把分母带回来

两组分别有 n1,n2n_1,n_2n1​,n2​ 个有效 token，局部均值为 m1,m2m_1,m_2m1​,m2​。先恢复局部和，再除以全局数量：

m=n1m1+n2m2n1+n2.m=\frac{n_1m_1+n_2m_2}{n_1+n_2}.m=n1​+n2​n1​m1​+n2​m2​​.

7 个 token 的均值为 2，5 个的均值为 3，合并结果是 29/12≈2.41666729/12\approx2.41666729/12≈2.416667。简单平均 2.5 隐含了两组权重相等，与本例的数据不符。

在实际系统中直接累计 sum 和 count 往往更清楚。没有有效样本时，接口应报告缺失或明确失败；不能除以 0，也不能把“没有观测”悄悄当成均值 0。这只是指标统计的规则，具体分布式框架怎样平均梯度还需单独核对。

小结：定义、样本和估计分别说明

密度通过面积给概率，条件概率必须保留条件方向。期望与方差分别描述位置和波动；样本均值的稳定性依赖采样条件。合并批次或设备指标时保留有效计数，才知道最后一个平均值究竟代表谁。
